## 待辦事項網站

純 HTML / CSS / JavaScript 製作的待辦事項清單，不需要任何安裝或建置。

### 功能

- 新增、完成、刪除待辦事項
- 雙擊文字即可編輯（Enter 儲存、Esc 取消）
- 篩選：全部 / 未完成 / 已完成
- 一鍵清除已完成項目
- 資料自動儲存在瀏覽器 localStorage
- 支援深色模式與手機版面

### 使用方式

直接用瀏覽器開啟 `index.html` 即可。

也可以在 GitHub repo 的 **Settings → Pages** 選擇 `main` 分支發佈，就能透過網址使用。
