## 待辦看板

純 HTML / CSS / JavaScript 製作的看板式待辦事項，不需要任何安裝或建置。

### 功能

- 多個看板分頁切換，預設有「個人」「工作」兩個；可新增、重新命名、刪除看板
- 每個看板可以建立專案分類（例如工作底下的不同專案），依名稱排序，可篩選「全部」或單一專案
- 不要的專案可以丟進垃圾桶（連同裡面的卡片），30 天內可以還原，之後自動永久刪除；每個看板各有自己的垃圾桶
- 頁面標題可以編輯；標題下方的激勵小語每個看板各自一句，也可以編輯
- 三個欄位：待辦 / 進行中 / 已完成
- 卡片可以標星號（優先處理）：星號卡片在每一欄都排在最上面，依更新時間由新到舊
- 每個看板都能搜尋卡片（標題、細項內容、專案名稱），符合的文字會標亮
- 每張卡片都屬於某個專案：先選專案，就能在該專案底下的每一欄直接新增卡片（「全部」頁面不能新增）
- 卡片細項編輯：標題、細項內容、截止日期、狀態、專案（點兩下卡片或按編輯圖示）
- 截止日期提示：今天 / 明天截止、逾期天數
- 拖曳卡片在欄位之間移動或調整順序（觸控裝置可用卡片上的 ← → 按鈕）
- 卡片可以移到其他專案或看板（資料夾圖示），也可以直接拖到專案標籤上
- 「已完成」超過 10 張時可以收合，只顯示最近 10 張；也可一鍵清除
- 淺色模式採用馬卡龍色系；可切換深色模式（預設跟隨系統，切換後會記住）
- 資料自動儲存在瀏覽器 localStorage（只存在這台電腦的這個瀏覽器）
- 右上角可以匯出備份（JSON 檔），在其他電腦或瀏覽器匯入即可還原；匯入會取代目前的資料
- 支援手機版面

## 股票紀錄

頁面上方的「看板／股票」可以切換到 `stocks.html`，記錄股票交易與股利。

- 記錄買進、賣出：手續費（0.1425%，可設定折扣與最低手續費）與證交稅自動計算，也可手動修改
- 記錄股利：現金股利（實際入帳金額）與股票股利（配股股數）
- 記錄資金進出：哪家銀行入金（轉入股票帳戶）或出金（轉回銀行）多少，並統計各銀行累計出資
- 期間篩選：7 天 / 30 天 / 3 個月 / 全部 / 自訂，也可以只看單一股票
- 統計：期間總收益、已實現損益（平均成本法）、股利收入、買進支出、賣出收入、淨入金
- 帳戶現金餘額：淨入金 + 賣出收入 + 現金股利 − 買進支出（計算到期間結束日，可用來對帳）
- 目前持股：平均成本、總成本；輸入現價即可估算市值與未實現損益
- 年度股利：每年各股票的現金股利與配股合計
- 下載 Excel 報表（.xlsx，依目前的期間與股票篩選），包含摘要、交易明細、股利明細、年度股利、目前持股、資金進出、各銀行出資
- 匯出／匯入 JSON 備份（與看板的備份分開）
- 依台股慣例紅色為賺、綠色為賠

### 使用方式

直接用瀏覽器開啟 `index.html` 即可。

也可以在 GitHub repo 的 **Settings → Pages** 選擇 `main` 分支發佈，就能透過網址使用。
