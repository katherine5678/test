## 待辦看板

純 HTML / CSS / JavaScript 製作的看板式待辦事項，不需要任何安裝或建置。

### 功能

- 三個欄位：待辦 / 進行中 / 已完成
- 每一欄都能直接新增卡片
- 拖曳卡片在欄位之間移動或調整順序（觸控裝置可用卡片上的 ← → 按鈕）
- 雙擊文字即可編輯（Enter 儲存、Esc 取消），刪除用 ✕
- 一鍵清除「已完成」欄
- 深色模式切換（預設跟隨系統，切換後會記住）
- 資料自動儲存在瀏覽器 localStorage
- 支援手機版面

### 使用方式

直接用瀏覽器開啟 `index.html` 即可。

也可以在 GitHub repo 的 **Settings → Pages** 選擇 `main` 分支發佈，就能透過網址使用。
