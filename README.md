## 待辦看板

純 HTML / CSS / JavaScript 製作的看板式待辦事項，不需要任何安裝或建置。

### 功能

- 多個看板分頁切換，預設有「個人」「工作」兩個；可新增、重新命名、刪除看板
- 每個看板可以建立專案分類（例如工作底下的不同專案），依名稱排序，可篩選「全部」或單一專案
- 頁面標題可以編輯
- 四個欄位：優先處理 / 待辦 / 進行中 / 已完成
- 每一欄都能直接新增卡片；在某個專案底下新增的卡片會自動歸到該專案
- 卡片細項編輯：標題、細項內容、截止日期、狀態、專案（點兩下卡片或按編輯圖示）
- 截止日期提示：今天 / 明天截止、逾期天數
- 拖曳卡片在欄位之間移動或調整順序（觸控裝置可用卡片上的 ← → 按鈕）
- 卡片可以移到其他看板（資料夾圖示）
- 「已完成」超過 10 張時可以收合，只顯示最近 10 張；也可一鍵清除
- 淺色模式採用馬卡龍色系；可切換深色模式（預設跟隨系統，切換後會記住）
- 資料自動儲存在瀏覽器 localStorage
- 支援手機版面

### 使用方式

直接用瀏覽器開啟 `index.html` 即可。

也可以在 GitHub repo 的 **Settings → Pages** 選擇 `main` 分支發佈，就能透過網址使用。
